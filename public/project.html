SignPDF

AI-generated documents with animated signature artwork. From natural language prompt to signed PDF in seconds.

What It Does

01

Describe your document

"Create a signed business letter from VE LAB to Apple about AI partnership"

02

AI generates it

Gemini 2.5 Pro creates a structured document spec with signature placeholder

03

Signature embeds

Animated signature renders as PNG via ve-animesign, embeds in the final PDF

Signature Animations

Rendered in real-time by the ve-animesign Remotion engine. The signature composition draws with ink animation; the stamp composition applies an approval seal.

Handwritten Signature — 15 seconds, 30fps
Approval Stamp — 3 seconds, 30fps

Security & Signature Control

The current implementation is a working prototype. Before production use, the following enhancements are required:

Signature Authorization

  • Access control — Signature rendering must be gated behind authenticated sessions. Currently any API caller can trigger a signature render.
  • Signature ownership — Each user/entity should have their own signature composition, not a shared default. Signature assets need to be tied to verified identities.
  • Consent flow — Documents requiring signatures should include an explicit approval step before the signature is rendered and embedded.
  • Rate limiting — Prevent abuse of the signature rendering endpoint.

Blockchain Signature Ledger

We have a blockchain integration planned for the signature verification layer:

  • Immutable signature log — Every signature render event (who signed, what document, when) is recorded on-chain as a verifiable transaction.
  • Document hash anchoring — The PDF's content hash is anchored to the blockchain at signing time, creating a tamper-proof audit trail.
  • Verification endpoint — Anyone with a signed PDF can verify its authenticity by checking the document hash against the on-chain record.
  • Non-repudiation — The blockchain ledger ensures signers cannot deny having signed a document, as the transaction is cryptographically linked to their identity.

Additional Security Measures

  • Document encryption — Signed PDFs should support encryption at rest and password protection.
  • Audit logging — Full server-side audit trail of all document generation and signature events.
  • API key rotation — The render API key and signature runtime key need regular rotation and scoped permissions.

What's Next

  • Blockchain signature ledger — On-chain verification and non-repudiation for signed documents
  • Multi-user signature management — Each signer gets their own verified signature composition
  • More signature styles — Different compositions, company stamps, watermarks
  • Template system — Pre-built document templates that users customize
  • Batch generation — Generate multiple documents from a spreadsheet/CSV
  • White-label API — Offer as a service for other apps to embed document generation
  • GIF export — Animated signature as GIF for email signatures
