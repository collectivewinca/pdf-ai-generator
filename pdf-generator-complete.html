AI Assistant Endpoints

POST /api/assistant/understand

Understand user request and suggest best PDF type

POST /api/assistant/chat

Chat with the AI assistant about PDF creation

POST /api/assistant/generate

Generate a complete PDF request from natural language

GET /api/assistant/types

Get available PDF types (invoice, receipt, letter, etc.)

Example: Chat with AI

curl -X POST https://pdf-ai-generator.exe.xyz:3005/api/assistant/chat \

  }'

📦 JSON-Render Integration

JSON-Render provides a component catalog that defines how JSON specs map to React-PDF components.

Available Components

Component Description
Document Root PDF container with metadata
Page Individual pages (A4, Letter, etc.)
Text Text content with styling
View Container for grouping elements
Image Images and logos
Table Tabular data

JSON-Render Endpoints

GET /api/json-render/catalog

Get the PDF component catalog

POST /api/json-render/render

Render PDF using JSON-Render catalog

Get Catalog

curl https://pdf-ai-generator.exe.xyz:3005/api/json-render/catalog

Response

{
  "name": "PDF Components",
  "description": "JSON-Render catalog for PDF generation",
  "components": ["Document", "Page", "Text", "View", "Image", "Table", "TableRow", "TableCell"],
  "version": "1.0.0"
}
